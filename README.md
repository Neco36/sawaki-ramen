# スタミナラーメンさわき 公式ホームページ

仙台市青葉区川内亀岡町「スタミナラーメンさわき」のホームページです。日本語・English・中文（简体）に対応しています。

## ファイル
- `index.html` … ページ本体（HTML・CSS・JavaScript をこの1ファイルにまとめています）

## 文言・メニューの直し方
`index.html` の下の方にある `const DICT = ...` の中に、言語ごと（`ja` / `en` / `zh`）の文章とメニューがまとまっています。値段やメニュー名を変えるときは、3か国語すべてを同じように直してください。

## 言語の指定
URL の末尾に `?lang=en` や `?lang=zh` を付けると、その言語で開きます。
